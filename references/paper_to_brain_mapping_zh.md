## 1. 问题与目标

| 论文思想 | BRAIN 实现 | 控制措施 |
|---|---|---|
| 市场含噪、厚尾、相关且非平稳 | 将一次模拟视为弱证据，保留年度/压力诊断和独立重复运行 | 禁止把一次高 Sharpe 等同于稳定 Alpha |
| 回测反馈会造成语义漂移 | 强制结构化假设、可观测代理、失败模式和语义门控 | 拒绝没有对应字段类别支持的叙事 |
| 随机重新生成会丢失已验证经验 | 归档候选、设置、结果、谱系和故障诊断 | 使用不可覆盖的 JSONL 事件 |
| 局部开发会造成拥挤 | 初始化 10 个类别/机制方向，并过滤结构和 PnL 冗余 | 参数变化不算新研究方向 |
| Alpha 目标是有效性减去正则化 | 使用质量、新颖性、风险、换手、复杂度和失败门控组成的固定奖励 | 保存奖励分项 |
| 优化轨迹生成策略 | 让 AI Agent 消费由归档结果生成的确定性变异/交叉任务 | 禁止 Agent 在看到结果后重新定义评价 |

## 2. 框架组件

| 论文组件 | BRAIN 实现 |
|---|---|
| Diversified Planning Initialization | `evolve_skill.py init` 创建 10 个互补研究方向和规划任务包 |
| 从观测、先验和参数生成假设 | 候选 Schema 保存机制、周期、方向、代理、主张和失败模式 |
| 语义描述 `d` | `semantic_description` 与代理角色 |
| 算子库 `O` | 已验证 FastExpr Allowlist 和字段类型路由 |
| AST 中间表示 | 确定性 Token/括号结构、字段提取、深度和结构 n-gram |
| 编译为代码 `c` | 将表达式发送到 BRAIN Simulation 编译器 |
| 实现修复 | 在冻结假设的前提下，最多修复两次语法/单位/算子错误 |
| 假设-描述-表达式一致性 | 可观测代理和字段类别证据门控 |
| 表达式-代码一致性 | 提交的 FastExpr 即符号表达式；模拟返回证明编译结果 |
| 复杂度 `C(f)` | 字符数、字段数、深度和自由参数比例的明确上限 |
| 最大公共子树冗余 | 使用标准化的抽象 Token n-gram 与字段 Jaccard 加权相似度 |
| 功能冗余 | 按日期对齐的每日 PnL 变化绝对相关性 |
| 评价历史 | 私有运行中的只追加 candidates、evaluations 和 events 文件 |
| 最终因子池 | 按奖励贪心选择并执行结构/PnL 相关门控 |

## 3. 进化机制

| 论文思想 | BRAIN 实现 | 机构化修正 |
|---|---|---|
| 按低相关性分组 Seed 因子 | 从不同 BRAIN 字段类别开始，随后使用 ACTIVE 每日 PnL 相关性 | 禁止假设公开模板天然独立 |
| Mutation 定位最有害节点 | `diagnose_evaluation` 将失败类型映射为实现、实现结构或机制级修改深度 | 规则诊断不是因果证明；ACTIVE 仅作示范 |
| 冻结前缀并修改局部片段 | Mutation 任务明确列出 `freeze` 和 `revise` | 每个任务只生成一个子节点 |
| 机制级变异 | 低 Sharpe 或高相关时强制修改机制/类别 | 禁止只调窗口 |
| Crossover 选择高奖励父节点 | 至少一方有成功证据；按 dominant mechanism、谱系、字段、结构、失败模式和 PnL 选择互补父代 | 近门槛轨迹可作第二父代；相似度防薄包装但不最大化正交 |
| 复用假设模板、构造和修复行为 | 交叉任务包含父假设和指标 | 子节点必须连贯，禁止拼接表达式 |
| 可追踪谱系 | 每个子节点记录 Operation 和 Parents | 原始谱系保存在私有目录 |
| 主搜索执行 5 个 Cycle | 默认目标为 5 次迭代 | 这是预算，不是性能保证 |
| 最多可持续改进至 15 次 | 最多允许 15 次并分析收敛 | 饱和时提前停止，不机械追求第 11-12 次 |
| 每个假设最多3个表达式；每轮Mutation后再Crossover | 初始规划一次；后续固定14 Mutation → 评价 → 6 Crossover | 14/6是20次BRAIN预算映射，不声称是论文唯一比例 |

## 4. 实验思想

| 论文实验或主张 | Skill 处理方式 |
|---|---|
| IC、ICIR、RankIC、RankICIR | 当前脚本没有相同因子面板接口，禁止编造 |
| ARR、IR、MDD | 使用具有平台含义的 BRAIN Returns、Sharpe、Drawdown、Fitness、Turnover 和 Margin |
| 因子池统一使用 LightGBM | BRAIN 公式接口无法复现；使用受控 Alpha 池，但禁止声称模型等价 |
| 对 Planning、Mutation、Crossover 和门控做消融 | 用多个独立 Seed/运行比较完整奖励分布 |
| 跨 Seed 稳健性 | 创建独立 Run ID，报告运行间离散程度 |
| 日度 IC 显著性 | 每日 PnL 只用于相关和稳定性；如主张显著性，需在外部执行稳健推断 |
| 交易成本敏感性 | 使用 Turnover 和 Margin 作为平台代理；成本结论仍需外部执行测试 |
| Token 与算力预算 | 在事件中记录候选数、模拟、修复、迭代和耗时 |
| CSI300 到 CSI500/S&P500 Zero-shot | 先冻结表达式，验证目标字段，并明确记录任何重新拟合或修改 |
| 按年度分析 Alpha Decay | `analyze_run.py` 输出年度每日 PnL 变化诊断 |
| 市场状态迁移和持续微观结构渠道 | 横跨慢速基本面、隔夜/新闻、波动率和价量类别提出假设，再进行验证 |
| 2025 年 4 月压力期 | 向 `analyze_run.py` 提供明确日期，报告 PnL 单位、样本数、回撤和正收益日占比 |
| 因子级语义诊断 | 比较研究方向、字段类别、失败模式和年度结果 |
| 迭代收敛 | 按迭代报告平均、最佳和最佳累计奖励 |
| 因子池约为已挖掘因子的 50% | 默认 Pool fraction 为 0.50，并设置绝对上限；该值可配置 |

## 5. 案例研究教训

将论文中的 Institutional Momentum 案例保留为反面控制：

- 禁止只根据价量相关性推断机构持仓。
- 禁止只根据日内平均收益推断散户关注。
- 表达式中没有波动率代理时，禁止声称使用动态波动率加权。
- 子节点轮次早于父节点时，禁止接受该谱系。
- 收益改善但风险指标恶化且部署结论为拒绝时，禁止称为成功子节点。
- 删除变量与自身相关等恒等项。

这些要求通过可观测代理、字段类别证据、明确谱系、指标门控和表达式审查实现。

## 6. 无法迁移的组件

当前 BRAIN 公式 Alpha 接口无法诚实复现：

- 论文的 CSI300、CSI500、S&P500 数据和时间切分；
- 次日 Close 标签和 LightGBM 下游模型；
- 持有 50 只、每日替换 5 只的 TopkDropoutStrategy；
- 论文的准确交易成本模型；
- 论文报告的 IC、收益、回撤、消融和迁移数值；
- PDF 未披露的专有 LLM Prompt、轨迹奖励、阈值和父节点选择细节。

禁止声称等价。只实现可迁移的研究逻辑，并明确标注平台特定指标。
